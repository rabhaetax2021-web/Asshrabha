# UI Primitives

This folder contains the foundational UI primitives used across the app. Use these components to ensure consistent spacing, colors, and behavior.

Usage
- Import primitives from `@/components/ui/*`.
- Prefer `Button`, `Input`, `Card` for new UI work.

Notes
- These components use the design tokens defined in `src/app/globals.css`.
- Keep components lean and avoid heavy dependencies.
